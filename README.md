# High Cars

Web de un concesionario de coches alemanes de alta gama (BMW M, Mercedes-AMG, Porsche y
Audi Sport) en km 0 y de ocasión.

La web está en [`site/`](site/) (Next.js 16, Tailwind CSS 4, Motion).

```bash
cd site
npm install
npm run dev      # http://localhost:3000
```

Requiere Node.js 20.9 o superior.

El resto del repo (`CLAUDE.md`, `.claude/skills/`, `docs/`) es
[claude-webkit](https://github.com/Hainrixz/claude-webkit), el flujo guiado con el que
Claude Code construye y modifica la web.
